# 長周期地震動階級

計測震度が「その場所がどれくらい強く揺れたか」を表すのに対し、長周期地震動階級は「その揺れで高層ビルの上層階がどれくらい揺さぶられるか」を表します。周期の長いゆっくりした揺れは、震度としては大きくならなくても高層階を大きく揺らすことがあるため、気象庁が別の指標として定義したものです。

考え方は単純です。高層ビルを1自由度の減衰振動系(バネにつながれた錘)としてモデル化し、固有周期の違うものを32個並べます。そこに観測された地面の揺れを入力し、各振動子がどれだけの速度で揺れるかを求めて、その最大値 Sva を4段階の階級に対応させます。

ただし「地表の記録から高層階の応答を推計する」ものであって、特定の建物の構造解析ではありません。

なお本パッケージが実装しているのは**観測された記録から階級を求める計算**です。緊急地震速報で発表される「長周期地震動階級の予測」は、震源要素から距離減衰式で推定する別の問題であり、実装していません。

## 使い方

```python
from pyshindo.long_period import calculate_long_period_class

# 水平2成分だけを渡します(上下動は使いません)
result = calculate_long_period_class(acceleration[:, :2], 100.0, unit="gal")

result.long_period_class   # "0" 〜 "4"
result.max_sva_cm_s        # 絶対速度応答の最大値 [cm/s]
result.critical_period_s   # その最大値を与えた周期
result.sva_cm_s            # 周期ごとのSva (32個)
result.bands               # 周期帯別(1秒台〜7秒台)の最大Svaと階級
```

逐次入力には `LongPeriodEstimator` を使います。階級は記録全体の最大値で決まるので、逐次側の値は「これまでに見た範囲での暫定値」であり、単調に増えていきます。

実行例は [`examples/08_long_period.py`](../examples/08_long_period.py) にあります。

## 計算の流れ

1. 水平2成分の加速度に、周期20秒以上をカットする2次ハイパスフィルタをかける
2. フィルタ後の加速度で、32個の1自由度減衰系(減衰定数5%、周期1.6〜7.8秒)を駆動し、**相対**速度応答を得る
3. 同じフィルタ後の加速度を積分して、**地動**速度を得る
4. 2と3を足して**絶対**速度応答を得る(絶対速度応答 = 相対速度応答 + 地動速度)
5. 各時刻で水平2成分をベクトル合成する
6. 周期ごとに時間方向の最大値をとり、Sva(T) を得る
7. 全周期での最大値から階級を決める

ここで「相対」「絶対」の区別が要点です。相対速度応答は地面に対する上層階の速度で、絶対速度応答は静止した空間に対する速度、つまり実際に人が感じる揺れです。固有周期より短い波が入ったとき錘は空間に静止するので絶対速度応答はゼロに近づき、固有周期より長い波が入ったとき錘は地面と一緒に動くので絶対速度応答は地動速度に一致します。この振る舞いを正しく出すために、手順3で地動速度を別途求めて足し込む必要があります。

## ハイパスフィルタ

手順1のフィルタは、気象庁が2016年11月27日に導入した改善手法です。それ以前は「周期5秒以上をカットする積分漸化式」を地動速度の算出だけに使い、相対速度応答には生の加速度を入れていました。この方式だと、相対速度応答と地動速度の間に位相のずれが生じ、両者を足したときに打ち消し合うはずの成分が残ってしまいます。結果として、固有周期より短い波が卓越する記録では過大評価、長い波が卓越する記録では過小評価になることが検討会で示されました。改善手法では、フィルタを加速度記録そのものに一度だけかけ、相対速度応答と地動速度の両方をその同じ波形から計算します。

漸化式は一次資料の記法どおりです。

```
y_t       = acc_t + a1*acc_(t-1) + a2*acc_(t-2) - b1*y_(t-1) - b2*y_(t-2)
acc_HPF_t = G0 * y_t
```

サンプリング周波数100 Hzでの定数:

```
a1 = -2.0      b1 = -1.995438545842
a2 =  1.0      b2 =  0.995448925627
               G0 =  0.997721867867
```

符号に注意が必要です。`b1` 自体が負で、式の上でさらに引くので、`y_(t-1)` の項は実質的に加算になります。この書き方は `scipy.signal.lfilter` の分母 `[1, b1, b2]` の規約とそのまま一致するので、実装では変換せずに使えます。

このフィルタの性質は本パッケージで独立に検証しました。

- 分子が `(1 - z^-1)^2` なので**直流利得は厳密に0**
- 極半径 0.99772 で安定
- -3 dB点は周期19.5秒(公称の「20秒」に対応)
- 対象周期帯での利得は、1.6秒で0.99998、**7.8秒で0.98739**

最後の点は見落としやすいところで、最長周期側で約1.3%減衰します。これは定義の一部なので補正せずそのまま含めます。

### 100 Hz以外のサンプリング周波数

公表されている定数は100 Hz専用です。それ以外のレートでは、公表定数から逆算した等価アナログ原型を使って係数を組み直します。逆算してみると、**減衰比が `zeta = 1/sqrt(2)`、つまり2次バタワース**そのもので、極は matched-z 写像 `z = exp(s*dt)`(双一次変換ではない)、`G0` はナイキスト周波数で利得1になる正規化、と分かりました。固有周期は19.48秒で、公称の20秒とは少しずれています。

この再構成は100 Hzで公表値を4e-9(公表されている桁数の精度)で再現します。とはいえ公表された経路ではないので、100 Hz以外では警告を出し `reference_conditions_met` は `False` になります。

## 1自由度減衰系の応答

運動方程式は次の形で、これを**線形加速度法**で直接積分します(大崎順彦(1994)『新・地震動のスペクトル解析入門』に基づくと気象庁資料に明記されています)。

```
ACC(t) + 2*h*w*VEL(t) + w^2*DIS(t) = -A(t)
```

初期条件は次のとおりで、**速度は0ではありません**。

```
DIS(1) = 0
VEL(1) = -A(1)*dt
```

漸化式(`n = 1 ... NT-1` で `n+1` を生成):

```
DIS(n+1) = A11*DIS(n) + A12*VEL(n) + B11*A(n) + B12*A(n+1)
VEL(n+1) = A21*DIS(n) + A22*VEL(n) + B21*A(n) + B22*A(n+1)
```

係数は、固有円振動数 `w = 2*pi/T`、減衰固有円振動数 `wd = w*sqrt(1-h^2)`、`e = exp(-h*w*dt)` として次のとおりです(変数名は `_core.py` の実装と同じにしてあります)。

```
A11 = e*(cos(wd*dt) + (h*w/wd)*sin(wd*dt))
A12 = e*sin(wd*dt)/wd
A21 = -e*(w^2/wd)*sin(wd*dt)
A22 = e*(cos(wd*dt) - (h*w/wd)*sin(wd*dt))

B11 = e*((1/w^2 + 2*h/(w^3*dt))*cos(wd*dt)
         + (h/(w*wd) - (1-2*h^2)/(w^2*wd*dt))*sin(wd*dt)) - 2*h/(w^3*dt)
B12 = e*(-(2*h/(w^3*dt))*cos(wd*dt) + ((1-2*h^2)/(w^2*wd*dt))*sin(wd*dt))
      - 1/w^2 + 2*h/(w^3*dt)
B21 = e*(-(1/(w^2*dt))*cos(wd*dt) - (h/(w*wd*dt) + 1/wd)*sin(wd*dt)) + 1/(w^2*dt)
B22 = e*((1/(w^2*dt))*cos(wd*dt) + (h/(w*wd*dt))*sin(wd*dt)) - 1/(w^2*dt)
```

この閉形式が正しいことは、行列指数関数による一次ホールド離散化と独立に突き合わせて確認しました。32周期すべてで `max|dA| = 1e-16`、`max|dB| = 1e-14` で一致します。この一致は「線形加速度法とは各区間で加速度を線形補間する一次ホールドのことである」という解釈が正しいことも同時に示していて、次の節の判断根拠になります。

### 同じ式を速く解く

上の漸化式 `x[n+1] = A x[n] + B0 u[n] + B1 u[n+1]` は線形時不変系の状態空間表現なので、HPF後の加速度から相対速度応答への伝達関数を厳密に書き下せます。

```
V(z)     B22*z^2 + (B21 - A11*B22 + A21*B12)*z + (A21*B11 - A11*B21)
---- = ---------------------------------------------------------------
U(z)              z^2 - (A11 + A22)*z + (A11*A22 - A12*A21)
```

これは公式の手順を別のアルゴリズムで置き換えたものではありません。**同じ系の同じ厳密解を、別の演算順序で求めているだけ**です。係数も上の閉形式からその場で導出しているので、コード上の一次情報は A11..B22 のままです。

一括計算(`solver="filter"`、既定)はこの形で周期ごとに `lfilter` を呼び、逐次ループがコンパイル済みコードに移るぶん約13倍速くなります。逐次計算(`LongPeriodEstimator`)は漸化式のままです。32個の振動子は縦続ではなく並列なので、1サンプルずつ流す場合は周期の数だけ `lfilter` を呼ぶことになり、かえって遅くなるためです。

両者の差は浮動小数点の丸めだけで、公式の初期条件 `VEL(1) = -A(1)*dt` を伝達関数側にも持ち込んだうえで、相対1e-12程度で一致します。厳密に逐次と同じ値が必要な場合は `solver="recurrence"` を指定してください。

## 地動速度をどう積分するか

一次資料は「HPF後の加速度を積分して地動速度を得る」とは述べていますが、**離散化の規約(初期値と添字の対応)までは書いていません**。本パッケージは台形則と `V(1) = 0` を採用しています。根拠は2つあります。

第一に、数学的な整合性です。前節で確認したとおり漸化式は一次ホールド、つまり各区間で加速度が線形だと仮定しています。同じ仮定のもとでは区間 `[t_n, t_(n+1)]` の積分は

```
integral(a dt) = dt*(a_n + a_(n+1))/2
```

と**厳密に一致**します。台形則は近似の一種ではなく、仕様の他の部分と整合する唯一の積分則ということです。

第二に、実際の照合結果です。気象庁が公開している公式のSvaと突き合わせたところ、台形則以外の規約では3桁悪化しました(次節)。

## 公式値との照合

気象庁は各地震について、加速度波形CSVと、それを基に自ら計算した絶対速度応答スペクトルCSVの両方を公開しています。`velsp` ファイルの `0.050_hz` 列(減衰5%・水平動合成)が、本パッケージの計算対象そのものです。つまり公開データだけで端から端まで検証できます。

2026年8月23日 茨城県南部の地震(M5.9、最大階級2)で照合した結果:

| 観測点 | 公式の最大Sva | 本実装 | 最大値での相対差 |
|---|---|---|---|
| 47052 浦安市日の出 | 41.8530 cm/s | 41.852904 cm/s | 2.3e-06 |
| 41317 東京江戸川区中央 | 16.4456 cm/s | 16.445578 cm/s | 1.3e-06 |
| 47629 水戸市金町 | 5.1811 cm/s | 5.181280 cm/s | 3.5e-05 |

階級はいずれも一致しました。全32周期での最大相対差は約1e-4ですが、これはSvaが小さい周期に現れており、公表値が小数第4位、入力波形が小数第3位で丸められていることと整合します。

積分規約の切り分けは、観測点47052で次のようになりました。

| 積分則 | 最大値での相対差 | 全周期での最大相対差 |
|---|---|---|
| **台形則(採用)** | **2.3e-06** | **1.1e-04** |
| 前進オイラー `dt*a(n)` | 3.7e-03 | 9.7e-02 |
| 後退オイラー `dt*a(n-1)` | 3.9e-03 | 1.1e-01 |

3桁の差がついているので、台形則が正解であることは実証的に確定したと考えています。

再現手順は [`examples/08_long_period.py`](../examples/08_long_period.py) にあります(実行時にダウンロードします。記録の再配布はしません)。

## 水平合成と階級

手順5の水平合成は、各時刻・各周期でNS/EWをベクトル合成してから時間方向の最大値を取ります。

```
horizontal(n, T) = hypot(absVEL_NS(n,T), absVEL_EW(n,T))
Sva(T)           = max_n horizontal(n, T)
Sva_max          = max_T Sva(T)
```

これは気象庁の「手法B」で、2016年に「成分ごとの最大値のうち大きい方」(手法A)から変更されました。建物は必ずしも東西・南北を向いていないため、という理由です。

合成がユークリッドノルムであることから、**結果は水平面内の回転に対して不変**です。センサーの設置方位が分からない記録(SEEDの `1`/`2` チャンネルなど)でもそのまま計算できます。

階級の区分は下限以上・上限未満です。

| 階級 | Sva |
|---|---|
| 0 | Sva < 5 cm/s(階級1に達しない) |
| 1 | 5 以上 15 未満 |
| 2 | 15 以上 50 未満 |
| 3 | 50 以上 100 未満 |
| 4 | 100 以上 |

「階級0」は気象庁自身が公開データで用いている区分です。

### 周期帯別階級

気象庁は全体の階級に加えて、周期帯ごとの階級も公表しています。帯は周期の整数部で区切られます。

| 帯 | 周期 |
|---|---|
| 1秒台 | 1.6, 1.8 |
| 2秒台 | 2.0 〜 2.8 |
| 3秒台 | 3.0 〜 3.8 |
| 4秒台 | 4.0 〜 4.8 |
| 5秒台 | 5.0 〜 5.8 |
| 6秒台 | 6.0 〜 6.8 |
| 7秒台 | 7.0 〜 7.8 |

`LongPeriodResult.bands` が各帯の最大Svaと階級を返します(公式の周期グリッドを使ったときのみ)。

## 注意点

**記録の先頭にオフセットがあると過大評価になります。** ハイパスフィルタの直流利得は厳密に0ですが、それは定常状態の話です。記録がゼロでない値から始まると、フィルタは先頭でステップ入力を受けたことになり、その過渡応答が測定対象である1.6〜7.8秒帯にそのまま乗ります。揺れが全く無くオフセットだけの信号でも有限のSvaが出るほどの影響があります。

気象庁の記録は地震前の静穏部から始まるためこの問題は生じませんが、そうでない記録を入力する場合は `remove_offset` などで先に補正してください。本パッケージは自動補正しません(どの補正が適切かは記録によるためです)。

**上下動は使いません。** 3成分を渡すとエラーになります。`acceleration[:, :2]` のように水平2成分を明示的に切り出してください。黙って上下動を捨てるより、意図を明示してもらう方が安全だと判断しました。
